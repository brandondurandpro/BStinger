# The Linux CI jobs, one per line for each Ubuntu version and display session: the steps of `run-tests` each job runs,
# separated by commas. A step is `non-ui` (the modules without UI tests, together), a line of ui-test-modules.txt (the
# whole module) or a shard of a module, `<module>.<shard>` (see test-shards.txt). Every module must be run exactly once:
# whole, or all of its shards (`rest` included), each in exactly one group; tools/ci/check-test-groups checks it, and
# the CI runs that check. The desktop app's startup is checked by the group that has `non-ui`.
